## I.G.Y — Isometric City-Builder

role Tech Lead team 5 members year 09/2025 — 06/2026 stack C++ · OpenGL · Custom Engine

Quarter-view city-builder simulation inspired by Caesar 3 and SimCity 2000, built from the ground up on a custom C++/OpenGL engine. As Tech Lead I owned the engine and technical architecture across rendering, simulation, and AI.

### Architecture & Leadership

  • Owned the overall technical architecture, defining module boundaries and the main update/render loop so simulation, rendering, and AI could evolve independently
  • Set technical direction for a team of 5: made the core engine and tooling decisions, ran code reviews, and coordinated integration of each member's systems into a single build
  • Onboarded teammates with little graphics or engine experience, writing usage examples and lightweight docs so they could contribute gameplay and AI features without touching low-level code

### Engine — Dokev

  • Grew my Computer Graphics course renderer into a reusable engine, Dokev, wrapping raw OpenGL state and draw calls into single-function shape drawing, coloring, and texturing
  • Built core engine modules: a scene graph for hierarchical transforms, a resource manager for textures and shared assets, and an event bus for decoupled communication between systems
  • Added a pan/zoom camera, texture atlasing, and sprite batching so the renderer could push a full tile map plus hundreds of agents without stalling

### Citizen AI & Pathfinding

  • Designed citizen AI using utility-based decision making: needs (work, food, leisure, rest) decay over time and score competing actions, with a state machine executing the chosen behavior
  • Implemented A* pathfinding on the tile grid so citizens route around buildings and terrain, with a request queue and path caching to spread cost across frames and re-path when the map changes
  • Used a spatial grid and dirty-flag updates for neighbor queries and to skip idle tiles, sustaining hundreds of active agents at a stable frame rate

## MINIGAME COLLECTION

role Solo Developer team Solo year Jul 2025 stack C++ · Raylib

A minigame collection built in C++ with Raylib. Rather than one big game, I used it as a sandbox to implement three self-contained games, each exploring a distinct technical problem — pathfinding, constraint solving, and gameplay simulation.

### 01  Maze Escape  // A* Pathfinding

A 2D maze-escape game. The player must reach the exit while avoiding roaming enemies that hunt the player using A* pathfinding on the maze grid.

### 02  Sudoku  // Backtracking

A playable Sudoku game with puzzle generation and solving driven by a recursive backtracking algorithm that fills and validates the board.

### 03  Futsal Manager  // Gameplay Simulation

A prototype 4-vs-4 futsal simulation game. Models player movement, possession, and match flow as a real-time gameplay simulation sandbox.
